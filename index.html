DEVELOPER INTEGRATION ARCHITECTURE

Backend Training Contract

To connect this frontend to a real GPU training worker (PyTorch, Ray Train, or Celery), implement the following endpoints and data contracts:

POST /api/v1/training/pretrained

Dispatches pre-trained fine-tuning or head-only adaptation. Validates model registry checkpoint.

{
  "mode": "pretrained",
  "model_id": "distilbert-base-uncased",
  "method": "classification-head", // or "full" or "lora"
  "dataset_id": "ds_sentiment_v1",
  "hyperparameters": {
    "epochs": 3,
    "learning_rate": 0.00002,
    "batch_size": 16,
    "validation_split": 0.20
  },
  "governance_verified": true
}
POST /api/v1/training/scratch

Initializes model from scratch with random weights ($W_0$). Strictly refuses external checkpoints.

{
  "mode": "scratch",
  "architecture": "mlp", // "conv1d", "bilstm", "mini-transformer", "tabresnet"
  "size": "small",
  "task": "binary_classification",
  "init_scheme": "glorot_uniform",
  "dataset_id": "ds_churn_v1",
  "zero_checkpoints_enforced": true,
  "preprocessing": {
    "scaler": "standard",
    "encoding": "onehot",
    "split": [0.70, 0.15, 0.15]
  },
  "hyperparameters": {
    "epochs": 50,
    "learning_rate": 0.001,
    "batch_size": 32,
    "dropout": 0.2
  }
}
WSS /api/v1/training/jobs/{job_id}/stream

WebSocket stream emitting live epoch progress, train/val losses, logs, and checkpoint artifacts.
